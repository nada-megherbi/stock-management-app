# 📦 Stock Management App

A management application developed in **Java** featuring a structured architecture (DAO, Model, View) and a relational database connection via **JDBC**.

## 🚀 Features:
- Well-structured architecture ('dao', 'database', 'model', 'view')
- Connection and queries to a relational database (MariaDB)
- Data manipulation and management (Add, view, update)

## 🛠️ Technologies Used:
- **Language:** Java
- **Database / Connectivity:** JDBC, MariaDB
- **Tools:** VS Code, Git / GitHub

## 📂 Project Structure:
- "dao/" : Data Access Object classes for database operations.
- "database/" : Database configuration and connection handling.
- "model/" : Entity and data model classes.
- "view/" : User interface .
- "Main.java" : Application entry point.
